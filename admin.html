First-time setup: sign in with a GitHub token

How do I get an access token?
  1. Sign in to GitHub with an account that can edit the khiri1234/qasr repository.
  2. Open Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → khiri1234/qasr.
  4. Permissions: Contents → Read and write. Nothing else is needed.
  5. Generate, copy the token, and paste it above. Keep it private — anyone with it can edit the store.
